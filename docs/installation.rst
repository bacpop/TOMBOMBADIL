Installation
============

The easiest way to install is via pip at the moment. TOMBOMBADIL requires Python 3.14 or newer. 

# Create a fresh environment
conda create -n tombombadil python=3.14 pip -y

# Activate it
conda activate tombombadil

# Install directly from GitHub
python -m pip install git+https://github.com/bacpop/TOMBOMBADIL.git@v0.1.0
